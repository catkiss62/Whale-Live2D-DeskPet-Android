# Q版鲸鱼 Live2D Android 桌宠

这是独立于 Sen 的 Q版鲸鱼 Live2D 测试仓库。当前版本为
`v0.1.0-native-catalog`，目标是先验证购买模型的原生显示、完整表情/动作目录、
13类陪玩反应和 Android 系统悬浮桌宠，再讨论接入 AI 伴侣。

## 当前能力

- 使用 Live2D 官方 Cubism SDK for Java 5 R5 与 Android 原生 OpenGL。
- 支持直接导入“DS鼠控版.zip”，也支持选择同时包含鼠控版/面捕版内层 ZIP 的外层购买包；外层包会优先选择名称包含“鼠控”的内层 ZIP。
- 安全解压到 App 私有目录，包含路径穿越、文件数和解压总量限制。
- 不依赖 `model3.json` 已登记目录：运行时递归扫描模型目录中的全部
  `.exp3.json` 和 `.motion3.json`。
- 当前购买包实测可扫描44个原生表情/道具和8个原生动作。
- `motions/idle.motion3.json`持续循环；其余动作每次点击只播放一次，结束后自动恢复 idle。
- 原生表情可叠加，再次点击同项关闭；“还原全部”清空表情并恢复 idle。
- 提供13类可替换的语义陪玩反应：打招呼、庆祝、喜欢、害羞、疑惑、惊讶、难过、大哭、生气、晕乎、调皮、贴纸安慰和蛋包饭玩耍。
- 支持用户主动开启的系统悬浮桌宠；透明窗口可拖动，轻点触发调皮反应，常驻通知可关闭。
- 测试 APK 使用仓库内公开 debug keystore，仅用于公开测试包覆盖安装，不得用于正式发布。

## 模型边界

仓库和 APK **不包含** 用户购买的 Q版鲸鱼 ZIP、moc3、贴图、表情、动作或
VTube Studio 配置。首次安装后点击“导入ZIP”选择本机购买包。

## 首轮实机检查

1. 分别尝试直接选择鼠控版内层 ZIP 和选择外层购买包，确认都能得到
   “44个表情 / 8个动作”。
2. 检查静态画面、透明度、蒙版、原生物理和 idle 循环。
3. 逐个测试7个非 idle 动作，确认单次播放结束会恢复 idle。
4. 测试44个表情/道具的开关和“还原全部”。
5. 测试13类陪玩反应，记录组合不自然或模型缺失的项目。
6. 授予悬浮窗权限，测试桌宠显示、拖动、轻点反应、前后台切换与通知关闭。
