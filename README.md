# Q版鲸鱼 Live2D Android 桌宠

这是独立于 Sen 的 Q版鲸鱼 Live2D 测试仓库。当前测试版本为
`v0.2.1-full-controls`，本轮只验证购买模型的中文原生目录、完整原生按钮、13类陪玩反应
和灵动待机；系统悬浮桌宠暂不作为验收重点。

## 当前能力

- 使用 Live2D 官方 Cubism SDK for Java 5 R5 与 Android 原生 OpenGL。
- 支持直接导入“DS鼠控版.zip”，也支持选择同时包含鼠控版/面捕版内层 ZIP 的外层购买包；外层包会优先选择名称包含“鼠控”的内层 ZIP。
- 安全解压到 App 私有目录，包含路径穿越、文件数和解压总量限制。
- 识别购买包内 Info-ZIP Unicode Path 字段，避免旧版把中文文件名解码为乱码；
  从 v0.1.0 覆盖安装后需要重新导入一次 ZIP。
- 同时使用 GB18030 读取未标记 UTF-8 的旧式 ZIP 文件名，兼容 Android 未返回
  Unicode Path 字段的情况。
- 不依赖 `model3.json` 已登记目录：运行时递归扫描模型目录中的全部
  `.exp3.json` 和 `.motion3.json`。
- 当前购买包实测可扫描44个原生表情/道具和8个原生动作。
- 全部原生动作均保留且单次播放；`motions/idle.motion3.json`不再被误当作真人式待机，
  仍可在原生动作区手动测试。
- 增加独立的“关闭 / 自然 / 活泼”三档灵动待机：缓慢转头、视线、身体跟随、
  呼吸和随机眨眼；播放作者原生动作时自动暂停，结束后恢复。
- 原生表情可叠加，再次点击同项关闭；“还原全部”清空表情与动作。
- 提供13类可替换的语义陪玩反应：打招呼、庆祝、喜欢、害羞、疑惑、惊讶、难过、大哭、生气、晕乎、调皮、贴纸安慰和蛋包饭玩耍。
- 页面会显示陪玩映射可用数，正常应为 `13/13`；旧目录下不可用的组合会标记“重导入后”。
- 测试面板永远保留全部按钮；旧乱码目录会把44个表情/道具和8个动作显示为编号，
  仍可逐项测试，重新导入成功后自动显示中文。
- 支持用户主动开启的系统悬浮桌宠；透明窗口可拖动，轻点触发调皮反应，常驻通知可关闭。
- 测试 APK 使用仓库内公开 debug keystore，仅用于公开测试包覆盖安装，不得用于正式发布。

## 模型边界

仓库和 APK **不包含** 用户购买的 Q版鲸鱼 ZIP、moc3、贴图、表情、动作或
VTube Studio 配置。首次安装后点击“导入ZIP”选择本机购买包。

## v0.2.1 实机检查

1. 覆盖安装后重新点击“导入ZIP”；旧版已解压的乱码目录无法无损自动改名。
2. 分别尝试直接选择鼠控版内层 ZIP 和选择外层购买包，确认中文名称正常、
   显示“44个表情 / 8个动作”和“陪玩映射 13/13”。
   若仍是旧乱码目录，也应显示完整的编号按钮，不能再整块消失。
3. 在“关闭 / 自然 / 活泼”间切换，比较转头、眼神、身体、呼吸和眨眼的幅度。
4. 逐个测试8个原生动作，确认都是单次播放，播放期间灵动待机不会抢参数。
5. 测试44个表情/道具的开关和“还原全部”。
6. 测试13类陪玩反应，记录组合不自然或模型缺失的项目。
7. 本轮可不测试悬浮桌宠。
